# 画面遷移図（Screen Flow）

## 1. ユーザー管理フロー

```mermaid
graph TD
    A[ログイン] --> B{認証成功？}
    B -->|Yes| C[ダッシュボード]
    B -->|No| D[エラーページ]
    
    C --> E[ユーザー一覧]
    E --> F[ユーザー詳細]
    F --> G[ユーザー編集]
    G --> H[保存/更新]
    H --> I{成功？}
    I -->|Yes| C
    I -->|No| J[エラーメッセージ]
    
    E --> K[新規登録]
    K --> L[登録完了]
    L --> C
```

### 1.1 ユーザー管理詳細ページ構成
- **ヘッダー**: ログアウト、通知アイコン
- **メインエリア**: 
  - ユーザー一覧テーブル（検索、ソート機能）
  - ページネーション
- **サイドバー**: 
  - ユーザー統計
  - 最近のアクティビティ

## 2. 決済フロー

```mermaid
graph TD
    A[商品ページ] --> B[カートへ追加]
    B --> C[カート確認]
    C --> D[チェックアウト]
    D --> E{支払い方法選択}
    
    E -->|クレジットカード| F[カード情報入力]
    E -->|コンビニ決済| G[決済完了画面]
    E -->|銀行振込| H[振込案内表示]
    
    F --> I[決済処理]
    I --> J{決済成功？}
    J -->|Yes| K[注文確定ページ]
    J -->|No| L[エラーメッセージ]
    
    G --> M[決済完了確認]
    M --> K
    
    H --> N[振込完了通知]
    N --> O[完了後チェック]
    O --> K
```

### 2.1 チェックアウトページ構成
- **ステップインジケーター**: 情報→配送→支払い→確認
- **フォームエリア**: 
  - 配送先住所入力
  - 支払い方法選択
- **要約エリア**: 
  - 商品一覧と合計金額
  - クーポンコード入力

## 3. 通知フロー

```mermaid
graph TD
    A[システムイベント発生] --> B{通知タイプ判定}
    
    B -->|メール| C[メール送信サービス呼び出し]
    B -->|プッシュ| D[プッシュ通知ゲートウェイ]
    B -->|SMS| E[SMS ゲートウェイ]
    
    C --> F[通知 DB 登録]
    D --> F
    E --> F
    
    F --> G[ユーザーアプリで取得]
    G --> H{未読？}
    H -->|Yes| I[表示リストに追加]
    H -->|No| J[アーカイブ処理]
```

### 3.1 通知センター構成
- **フィルター**: 未読/既読、タイプ別（メール/Push/SMS）
- **一覧表示**: 
  - タイトル、本文、日時
  - 開封状態のアイコン
- **アクション**: 
  - 詳細表示
  - 削除
  - マークして読み込み

## 4. 共通画面要素

### 4.1 ヘッダーコンポーネント
```
┌─────────────────────────────────────┐
│ ロゴ │ メニュー │ ユーザーアイコン   │
└─────────────────────────────────────┘
```

### 4.2 フッターコンポーネント
```
┌─────────────────────────────────────┐
│ お問い合わせ │ プライバシーポリシー │
└─────────────────────────────────────┘
```

### 4.3 エラーページテンプレート
```
┌─────────────────────────────────────┐
│                    🚫                │
│                  エラー              │
│               詳細メッセージ         │
│                   [戻る]             │
└─────────────────────────────────────┘
```

## 5. レスポンシブ対応

- **デスクトップ**: 3 列レイアウト（サイドバー＋メイン＋ナビゲーション）
- **タブレット**: 2 列レイアウト（サイドバーを折りたたみ可能）
- **モバイル**: 1 列レイアウト（ハンバーガーメニュー）

- キーボードナビゲーション対応
